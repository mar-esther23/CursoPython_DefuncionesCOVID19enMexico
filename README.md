# Análisis de datos con Python: Estadísticas de Defunciones Registradas (EDR-INEGI) en México 2020 con Python

El curso busca que los participantes aprendan a utilizar Python desde cero para el análisis de grandes conjuntos de datos, especialmente aquellos de interés público o social. Está diseñado para profesionales y estudiantes de ciencias de la salud con experiencia en bases de datos (como Excel) que necesitan programar para automatizar y escalar sus análisis.

- Aprender a usar Python desde cero y aplicarlo al análisis de grandes volúmenes de datos.
- Manipular, analizar y visualizar datos que reflejen aspectos críticos de la sociedad.
- Limpiar, transformar y analizar datos complejos para responder a preguntas clave.
- Convertir la información de los datos en conocimiento útil y aplicable.

## Temario
- Colab: uso, archivos y bibliotecas
- Notebooks y Python básico
- Indexación y selección de dataframes
- Limpieza de datos
- Remodelación de datos
- Visualización de datos
- Estadística y perfiladores de datos
